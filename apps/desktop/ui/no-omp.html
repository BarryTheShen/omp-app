omp is not installed

omp app runs the omp coding agent, and it could not find omp on this computer.

Install omp from omp.sh. On Linux, run this in a terminal: curl -fsSL https://omp.sh/install | sh. Then open omp app again.

If omp is installed already, check that omp --version prints a version in a terminal. omp app looks for omp on the PATH of your session, in ~/.bun/bin, ~/.local/bin, /usr/local/bin, /usr/bin, and in your login shell.
